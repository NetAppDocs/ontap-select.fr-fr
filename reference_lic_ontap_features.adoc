= Prise en charge de ONTAP Select pour les fonctionnalités ONTAP
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
ONTAP Select prend en charge la plupart des fonctionnalités ONTAP . De nombreuses fonctionnalités ONTAP sont automatiquement concédées sous licence pour chaque nœud lors du déploiement d'un cluster. Cependant, certaines fonctionnalités nécessitent une licence distincte.


NOTE: Les fonctionnalités ONTAP qui dépendent matériel ne sont généralement pas prises en charge par ONTAP Select.



[[ontap-features-licensed-by-default]]
[[licensed-ontap-features]]
== Fonctionnalités ONTAP concédées sous licence par défaut

Les fonctionnalités ONTAP suivantes sont prises en charge avec ONTAP Select et sont concédées sous licence par défaut.

| FlexCache | link:https://docs.netapp.com/us-en/ontap/flexcache-writeback/flexcache-write-back-guidelines.html["Écriture différée ONTAP FlexCache®"^] | ONTAP Select prend en charge les volumes de cache FlexCache® avec écriture différée. *Attention* : il existe des limites à l'écriture différée de FlexCache® avec ONTAP Select. Par exemple, la source ONTAP Select 9.16.1 peut se connecter aux versions ONTAP de destination 9.16.1, 9.17.1 ou 9.18.1.

== Fonctionnalités ONTAP sous licence séparée

Vous devez acquérir une licence distincte pour les fonctionnalités ONTAP suivantes, prises en charge par ONTAP Select mais qui ne sont pas concédées sous licence par défaut.

[cols="1,1,1"]
|===
| Fonctionnalité | Apprenez-en plus sur | Remarque 


| FabricPool | link:https://docs.netapp.com/us-en/ontap/concepts/fabricpool-concept.html["ONTAP FabricPool"^] | Vous n'avez pas besoin d'une licence FabricPool lorsque vous utilisez StorageGRID. 


| Les SDS dans MetroCluster | link:reference_plan_ots_mcc_sds.html["MetroCluster SDS pour ONTAP Select"] | Il s'agit d'une offre de licence premium ONTAP Select. 


| SnapMirror cloud | link:https://docs.netapp.com/us-en/ontap/concepts/snapmirror-cloud-backups-object-store-concept.html["SnapMirror cloud sauvegardes vers stockage objet"^] | Vous devez link:https://mysupport.netapp.com/site/help["ouvrir un ticket d'assistance non technique"^] pour obtenir une licence cloud SnapMirror. 
|===
