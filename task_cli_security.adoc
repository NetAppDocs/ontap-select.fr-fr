= Sécurisez un déploiement ONTAP Select
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Vous pouvez sécuriser un déploiement ONTAP Select en modifiant, si nécessaire, le mot de passe du compte administrateur de la machine virtuelle Deploy à l'aide de la ligne de commandes.

.Étapes
. Connectez-vous à la CLI de l'utilitaire de déploiement à l'aide du compte administrateur.
. Modifier le mot de passe :
`password modify`
. Répondez à toutes les invites correspondant à votre environnement.
